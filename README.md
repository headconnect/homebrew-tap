# headconnect/homebrew-tap

Homebrew casks for [headconnect](https://github.com/headconnect) apps.

```sh
brew install headconnect/tap/headroom
```

The `headroom` cask is bumped automatically by the
[headroom release workflow](https://github.com/headconnect/headroom/blob/main/.github/workflows/release.yml)
on every tagged release.
